# 项目实践（Projects）

这里放端到端学习项目。项目实践位于 Course、Lab、Core 之后，用来证明学习者能把多个机制合成一个闭环。

当前项目：

| 项目 | 目标 | 状态 |
| --- | --- | --- |
| [capstone-mini-runtime/](capstone-mini-runtime/) | 从 starter 失败开始，实现最小 `Search -> Read -> Edit -> Bash -> Verify` Runtime | active |

项目实践不是生产能力声明。完成项目只能说明你掌握了对应教学闭环，不能说明你已经实现了完整 Claude Code 替代品。
