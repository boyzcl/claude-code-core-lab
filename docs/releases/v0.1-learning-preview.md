# v0.1 Learning Preview Release Note

状态：released。

发布日期：2026-06-02。

---

## 1. 定位

`v0.1-learning-preview` 是 Claude Code Core Lab 的第一个公开学习预览版本。

它定位为：

```text
中文、证据优先、从零构建 Claude Code-like Agent Runtime 的工程课程。
```

它不是：

```text
Claude Code 官方源码
Claude Code 官方 Prompt
Claude Code 完整复刻
生产级 Claude Code 替代品
真实 Claude Code baseline
真实厂商账单或跨 agent RelativeScore
```

---

## 2. 本版本包含什么

| 层 | 内容 |
| --- | --- |
| Course | Course 00-18，覆盖教学标准、模型请求、动作选择、prompt 边界、完整 trace、产品心智、Lab 到 Core、Core 01-31 教学链 |
| Lab | Lab 01-08，覆盖 runtime loop、message store、read/search/bash、edit safety、context、plan mode、compaction、eval runner |
| Core | Core 01-31，覆盖最小运行时、模型网关、上下文、计划、压缩、评测、真实仓库、参考运行、成本、生产化升级和产品表层 |
| Practice | `exercises/`、`solutions/`、`projects/capstone-mini-runtime/` |
| Docs | README、learning-plan、start-here、troubleshooting、authority-map、open-source-boundary、capability coverage matrix |
| CI | `git diff --check`、`npm run docs:links`、`npm run verify:all` |


本版本不发布：

```text

.env.local
```
