# Lab

Lab 是单机制实验，用来在进入 Core 前先跑通一个小概念。

| Lab | 主题 |
| --- | --- |
| `lab-01` | Mock Runtime Loop |
| `lab-02` | Message Store |
| `lab-03` | Read / Search / Bash |
| `lab-04` | Edit Tool Safety |
| `lab-05` | Context Engine |
| `lab-06` | Plan Mode |
| `lab-07` | Compaction |
| `lab-08` | Eval Runner |

运行全部 Lab：

```bash
npm run verify:labs
```

源码和验证脚本在：

```text
../../src/lab01 ... ../../src/lab08
```
