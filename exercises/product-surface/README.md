# Core 27-31 练习：产品表层运行时边界

这一组练习对应 Course 18。目标是把 settings、hooks、memory、checkpoint、subagent 都讲成运行时对象、状态和强制边界。

## 最小任务

为每个产品表层机制填写：

| Core | 机制 | Runtime 对象 | 强制边界 | verify 命令 |
| --- | --- | --- | --- | --- |
| Core 27 | Settings / Permission |  |  | `npm run core:27:verify` |
| Core 28 | Hooks |  |  | `npm run core:28:verify` |
| Core 29 | Memory |  |  | `npm run core:29:verify` |
| Core 30 | Checkpoint / Rewind |  |  | `npm run core:30:verify` |
| Core 31 | Subagent |  |  | `npm run core:31:verify` |

完成信号：你能解释这些机制为什么不是单纯 UI 名词，也不是系统提示词里的几句话。
