# 参考解法（Solutions）

这里放练习和项目的参考解法。它们不是新的 current rule，也不替代 `src/core/*.verify.mjs` 的行为证据。

使用顺序：

```text
先读 exercises/ 或 projects/
先自己做一次
先跑对应 verify
再看 solutions/
```

当前入口：

| 路径 | 内容 |
| --- | --- |
| [course-00-05/](course-00-05/) | 产品心智和信息来源练习参考回答 |
| [lab-to-core/](lab-to-core/) | Lab 到 Core 映射参考回答 |
| [capstone-mini-runtime/](capstone-mini-runtime/) | 端到端 capstone 参考实现和 verify |

不要在参考答案里写入 API key、`.env.local`、真实 provider raw response、私有仓库代码或未脱敏 trace。
